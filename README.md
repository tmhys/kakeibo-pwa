# らくな家計簿 PWA

[tmhys/gas](https://github.com/tmhys/gas)（`rakuten-ledger`）をバックエンドにした、
「らくな家計簿」のような使い心地を目指す家計簿PWA。設計の経緯・意思決定は
[tmhys/my_apps の apps/kakeibo-pwa/DESIGN.md](https://github.com/tmhys/my_apps/blob/main/apps/kakeibo-pwa/DESIGN.md)
を参照。ビジネスロジック（自動取込・カテゴリ推定・重複排除・二重計上防止）は
すべて `gas` 側にあり、このアプリはUIと集計表示に徹する薄いクライアント。

## 使い方（初回セットアップ）

1. このリポジトリをホーム画面に追加して開く（下記「インストール」参照）
2. 右上 ⚙ から設定画面を開き、以下を入力
   - **WebApp URL**: `gas/rakuten-ledger` のデプロイURL（`/exec` で終わるもの）。
     スプレッドシートの「楽天家計簿」メニュー →「スマホ用URLを表示」で確認できる
   - **トークン**: `WEBAPP_TOKEN`（スクリプトプロパティに設定した値）
3. 「接続テスト」で疎通確認してから「設定を保存」

設定値は端末の `localStorage` に保存されるだけで、どこにも送信・同期されない
（URL自体が合言葉、という `gas` 側の前提を踏襲）。

## インストール（ホーム画面に追加）

GitHub Pagesで公開後、Android Chromeでこのサイトを開き、メニューから
「ホーム画面に追加」を選ぶとアプリのように使える。

## 画面

- **ホーム**: 当月の支出合計・前月同日比・**今日から月末まで1日あたり使えるお金**（予算があるとき）・
  **今月のペース**（累積の折れ線。先月・予算ペースと比較、着地見込み）・予算バー・
  **カテゴリ別の予算**（縦線は今日までの目安、ペースより早いと △、超えると ⚠）・
  臨時収入・カテゴリ別内訳・直近の取引。予算は設定画面で端末ごとに設定（総額を空にすると
  gas の `MONTHLY_BUDGET` を使う）
- **履歴**: **リスト／カレンダー**を切り替え。カレンダーは日ごとの支出を濃淡で表示し、
  日付をタップするとその日の明細。絞り込み条件はカレンダーにも効く。
  どの行もタップすると**詳細シート**（そのお店の通算・直近12か月・初回／最終、
  そのお店の履歴・月別推移へのリンク）。詳細シートから**カテゴリを直せる**（「このお店は今後も」で
  gas のカテゴリルールの先頭に追加、過去の同じお店もまとめて変更。gas の `Edit.gs`）。
  絞り込んだ結果は**CSVで書き出せる**（Excel で開ける BOM つき UTF-8）。
  検索は半角カナ・全角・大文字小文字・空白を区別しない（ﾄﾞﾄｰﾙ と ドトール が同じ）。全期間の取引（支出・収入。振替・集計も切り替えで表示可）を月・日ごとに一覧表示。
  利用先・カテゴリ・メモの検索、月・種別・カテゴリの絞り込みに加えて、「詳細な条件」で
  日付の範囲・金額の範囲・決済手段・並び順（新しい順／金額順）。絞り込むとその条件の
  月別推移グラフが出る（「Amazon にいつ・いくら使ったか」を調べる用）。ホームのカテゴリ行や
  「未分類」からその月の該当取引へ飛べる
- **分析**: 月別の支出の棒グラフ（直近12/24か月・全期間、カテゴリやお店で絞り込み可、
  点線は月平均）。棒をタップした月のカテゴリ別内訳（平均との差つき）、よく使うお店
  （回数・1回あたり）、曜日別の1日あたり平均。どの行もタップでその条件の履歴へ。
  ほかに**収支の推移と貯蓄率**（収入の記録がある月）、**固定費と変動費**（定期払いと
  通信・保険・サブスクなどのカテゴリを固定費とみなす）、**年間レポート**（カテゴリ×月の
  表を濃淡で。セルをタップでその月・カテゴリの明細）、**医療費控除の目安**（年間の医療費と
  10万円の基準、明細のCSV書き出し）、**データの点検**（未分類・同じ日に同じ金額の支出＝
  別経路からの二重取り込みの疑い）
- **レビュー**: 月次／四半期の振り返り。前の期間・直近平均（月次は6か月、四半期は4四半期）
  との比較、平均より増えた／減ったカテゴリ、大きな支払い、毎月ほぼ同額の支払い
  （サブスク・固定費の候補と、最近始まったもの）、コンビニの回数、同じ店での少額の
  繰り返し、手数料、未分類を、決まった規則でコメントする。文章での振り返りと
  「もっと安く買う方法」の提案は、毎月16日に Claude が Obsidian の月次ノートに書く
  （tmhys/github_obsidian の `01_Log/03_Money/`）
- **入力**: カテゴリボタン＋数字キーパッドで数秒入力。支出/収入を切り替え可能。
  直近3か月によく手入力した利用先とカテゴリをワンタップで入れられる（「よく使う」）。
  利用先は過去の取引から入力補完
- **銀行明細の取り込み**（入力画面の上から）: 楽天銀行・三菱UFJ銀行のサイトで落とした
  入出金明細CSVを選ぶと、振り分け（カード引落し・ATMは振替など）と重複判定の結果が出る。
  種別を直して「取り込む」。1万円以上は Zaim のメール経由で自動で入っているので、
  重複は自動で除かれる（gas の `Bank.gs`。CSVの文字コード変換だけアプリ側で行う）

## 既知の制約

- オフラインキューは無い。保存には通信が必要。
- `gas` 側に `page=all`（全取引を返すエンドポイント）が必要。古いデプロイのままだと
  「gas側が古いようです」と表示されるので、`rakuten-ledger` を更新して
  「新バージョン」で再デプロイする。
- 決済手段・カテゴリの一覧は `gas` 側から動的に取得しておらず、このアプリの
  設定画面でローカルに保持している値を使う（`gas` 側で決済手段やカテゴリの
  運用を変えたら、こちらの設定も手動で合わせる必要がある）。

## 技術的な注意点

- CORS: `gas` 側へのPOSTは `Content-Type: text/plain` で送ることでプリフライトを
  回避している（実機で動作確認済み）。
- ビルドステップなし。素のHTML/CSS/JSのみ。GitHub Pagesにそのままデプロイできる。
- 速度: Apps Script は1リクエストに数秒かかるため、起動時に `page=all` で全取引を
  1回だけ取得し、ホームの月次集計（`gas` の `computeSnapshot_` と同じ計算）も履歴も
  端末側で行う。画面・月の切り替えでは通信しない。取得結果は `localStorage` に
  保存し、次回起動時はそれで即描画してから裏で取り直す（右上 ↻ で手動更新、
  5分以上経ってアプリに戻ったときも自動更新）。履歴はスクロールに合わせて
  200件ずつ描画する。
- Service Worker は廃止した。以前の版はアプリ本体をキャッシュ優先で返していて
  更新が端末に届かないことがあったため、`sw.js` は自分とキャッシュを消すだけの
  中身にして残している（すでに入っている端末から外すため）。
