# らくな家計簿 PWA

[tmhys/gas](https://github.com/tmhys/gas)（`rakuten-ledger`）をバックエンドにした、
「らくな家計簿」のような使い心地を目指す家計簿PWA。設計の経緯・意思決定は
[tmhys/my_apps の apps/kakeibo-pwa/DESIGN.md](https://github.com/tmhys/my_apps/blob/main/apps/kakeibo-pwa/DESIGN.md)
を参照。ビジネスロジック（自動取込・カテゴリ推定・重複排除・二重計上防止）は
すべて `gas` 側にあり、このアプリはUIと集計表示に徹する薄いクライアント。

## 使い方（初回セットアップ）

1. このリポジトリをホーム画面に追加して開く（下記「インストール」参照）
2. 右上 ⚙ から設定画面を開き、以下を入力
   - **WebApp URL**: `gas/rakuten-ledger` のデプロイURL（`/exec` で終わるもの）。
     スプレッドシートの「楽天家計簿」メニュー →「スマホ用URLを表示」で確認できる
   - **トークン**: `WEBAPP_TOKEN`（スクリプトプロパティに設定した値）
3. 「接続テスト」で疎通確認してから「設定を保存」

設定値は端末の `localStorage` に保存されるだけで、どこにも送信・同期されない
（URL自体が合言葉、という `gas` 側の前提を踏襲）。

## インストール（ホーム画面に追加）

GitHub Pagesで公開後、Android Chromeでこのサイトを開き、メニューから
「ホーム画面に追加」を選ぶとアプリのように使える。

## 画面

- **ホーム**: 当月の支出合計・前月同日比・予算バー（`MONTHLY_BUDGET` 設定時のみ）・
  臨時収入・カテゴリ別内訳・直近の取引
- **履歴**: 全期間の取引（支出・収入。振替・集計も切り替えで表示可）を月・日ごとに一覧表示。
  利用先・カテゴリ・メモの検索、期間・種別・カテゴリの絞り込み。ホームのカテゴリ行や
  「未分類」からその月の該当取引へ飛べる
- **入力**: カテゴリボタン＋数字キーパッドで数秒入力。支出/収入を切り替え可能

## 既知の制約

- オフラインキューは無い。保存には通信が必要。
- `gas` 側に `page=all`（全取引を返すエンドポイント）が必要。古いデプロイのままだと
  「gas側が古いようです」と表示されるので、`rakuten-ledger` を更新して
  「新バージョン」で再デプロイする。
- 決済手段・カテゴリの一覧は `gas` 側から動的に取得しておらず、このアプリの
  設定画面でローカルに保持している値を使う（`gas` 側で決済手段やカテゴリの
  運用を変えたら、こちらの設定も手動で合わせる必要がある）。

## 技術的な注意点

- CORS: `gas` 側へのPOSTは `Content-Type: text/plain` で送ることでプリフライトを
  回避している（実機で動作確認済み）。
- ビルドステップなし。素のHTML/CSS/JSのみ。GitHub Pagesにそのままデプロイできる。
- 速度: Apps Script は1リクエストに数秒かかるため、起動時に `page=all` で全取引を
  1回だけ取得し、ホームの月次集計（`gas` の `computeSnapshot_` と同じ計算）も履歴も
  端末側で行う。画面・月の切り替えでは通信しない。取得結果は `localStorage` に
  保存し、次回起動時はそれで即描画してから裏で取り直す（右上 ↻ で手動更新、
  5分以上経ってアプリに戻ったときも自動更新）。履歴はスクロールに合わせて
  200件ずつ描画する。
- Service Worker は廃止した。以前の版はアプリ本体をキャッシュ優先で返していて
  更新が端末に届かないことがあったため、`sw.js` は自分とキャッシュを消すだけの
  中身にして残している（すでに入っている端末から外すため）。
